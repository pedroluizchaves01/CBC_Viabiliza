# Glossário — Viabiliza

Um termo, um significado, igual no banco, no código e na tela.

| Termo | Significado |
|---|---|
| **Obra / Projeto** | O estudo de viabilidade de uma construção específica, para um investidor específico. |
| **Investidor** | Cliente para quem o estudo é apresentado; pode ter mais de uma obra. |
| **Unidade** | Cada imóvel dentro de uma obra (normalmente 1; pode haver mais de uma). |
| **VGV** | Valor Geral de Vendas — receita total prevista com a venda das unidades. |
| **CUB** | Custo Unitário Básico — indicador oficial de custo de construção por m², calculado mensalmente pelo Sinduscon de cada estado. Ponto de partida do orçamento, não o custo final. |
| **Cronograma físico-financeiro** | Como o custo da obra se distribui ao longo dos meses, conforme o avanço físico da construção. |
| **Fluxo de caixa** | Entradas (vendas) e saídas (custos) mês a mês, e o saldo acumulado resultante. |
| **VPL** | Valor Presente Líquido — soma do fluxo de caixa trazido a valor de hoje, descontado a uma taxa. Positivo = o projeto rende acima do custo de capital. |
| **TIR** | Taxa Interna de Retorno — a taxa de desconto que zera o VPL; funciona como "a rentabilidade anual do projeto". |
| **Payback simples / descontado** | Tempo até o investimento ser recuperado; o descontado já considera o valor do dinheiro no tempo. |
| **Índice de Lucratividade (IL)** | VPL dividido pelo investimento; acima de 1 indica projeto viável. |
| **Exposição Máxima de Caixa (EMC)** | O maior valor negativo que o caixa do projeto chega a ter, e em que mês — o "pico" de capital necessário. |
| **Cenário** | Uma variação do mesmo projeto (ex.: Base, Conservador, Otimista), com ajustes de custo, prazo ou preço de venda. |
| **Carência** | Período no início do financiamento em que não há liberação de parcelas (ou não há cobrança de amortização). |
| **Liberação por medição** | O banco libera o valor financiado conforme o avanço físico da obra é comprovado, seguindo o cronograma. |
| **Amortização (SAC / Price)** | Forma como as parcelas do financiamento são pagas após a obra: SAC (parcelas decrescentes) ou Price (parcelas fixas). |
| **Comparável de mercado** | Um imóvel semelhante anunciado na região, usado como referência de preço de venda. |
